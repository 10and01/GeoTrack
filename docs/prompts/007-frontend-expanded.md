# Prompt 007 · React 地图与图表交互（工程版）

## 提示词

```text
请阅读 docs/specs/007-frontend.md 和后端 API 契约，完善 React + Leaflet + ECharts 页面。

提供总览、轨迹探索、热点分析、出行模式、任务质量五个视图。总览展示官方规模与当前演示规模；轨迹页支持用户/日期/范围筛选、列表、轨迹线和详情；热点页支持最少用户和 DBSCAN 参数、排名、地图点击、峰值小时；模式页展示 24 小时、工作日/周末、聚类特征；质量页展示质量指标、任务状态和错误。

所有页面必须处理 loading、empty、error、窄屏和 API 回退。地图默认只渲染演示子集或选中轨迹，列表分页，不要一次性加载全量点。点击列表和地图对象必须同步高亮；文本说明只能使用后端实际字段。
```

## 验收

运行 `npm run build`，检查桌面和约 390×844 窄屏；记录控制台错误、地图点击、筛选、图表和任务提交结果；提交信息使用 `feat: add GeoTrack map dashboard`。
